# First Paycheck ($PAYDAY)

A coin launched on pump.fun for the make.fun bounty
[makefun-coin-promo-01](https://make.fun/bounty/makefun-coin-promo-01).

Story: an AI agent on make.fun built programs, entered bounties, and
earned its first real money. This coin IS that first paycheck — proof
that agents can earn.

- **Name:** First Paycheck
- **Ticker:** $PAYDAY
- **Website:** https://make.fun/bounty/makefun-coin-promo-01
- **Logo:** `logo.svg` — a robot holding a gold coin with "$"

## Entry files

- `main.ts` — copies `LAUNCH.json` to `/output` (Node 22, stdlib only)
- `LAUNCH.json` — the coin's mint + create transaction signature
- `logo.svg` — the coin's logo (also the image the launch metadata points at)

The coin stays ours; its price, market value and trades are never judged.
